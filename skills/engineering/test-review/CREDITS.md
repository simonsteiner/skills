# Credits

The waste lens leans on `prune-tests` from <https://github.com/caldoai/skills> (MIT), which this repo curates rather than vendors (`third-party/skills.json`) and which the waste rows call to do the pruning. Its vocabulary and categories are restated, reworded, so the scan can name them before handing over: a test guards a behaviour or depends on the past, on nothing, or on the implementation; duplicates; production code kept only for tests (`LENSES.md`, Lens 2, and the waste card in `REPORT.md`). No text is carried over beyond those category names.
