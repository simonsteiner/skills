Add two engineering skills. `address-review-findings` pulls a PR's unresolved review threads via `gh`, triages each against the code, then fixes, pushes, replies, and resolves in one hands-off run — resolving only threads it actually addressed, and leaving anything needing a human open with the question in it. `sync-and-branch` fast-forwards the default branch and cuts a feature branch from it, branching into a new git worktree when the tree is dirty rather than stashing anything.
